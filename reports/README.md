## Запуск
1. Установите Node.js LTS с официального сайта https://nodejs.org/.
2. Откройте эту папку в VS Code. В меню Terminal → New Terminal выполните `npm install`.
3. Установите расширение Live Server от Ritwick Dey.
4. Нажмите правой кнопкой на `index.html` слева в списке файлов → Open with Live Server.

Без Live Server можно запустить `npx http-server . -p 8080 -c-1` и открыть http://127.0.0.1:8080/. Эта команда запускает вспомогательный сервер из npm; добавлять его в проект не нужно. Для остановки — Ctrl+C.

Двойной щелчок по HTML не подходит для JavaScript-модулей: нужен локальный HTTP-сервер.

## Проверка
- На главной — три авиакомпании.
- В фильтре введите `s7`: останется S7 Airlines. Регистр не важен.
- «Подробнее» открывает авиарейсы с пунктами отправления и назначения.
- «Назад» и «Домой» возвращают список; «Домой» видна на обеих страницах.
- «Добавить авиакомпанию» копирует первую карточку с новым id и её рейсами.
- «Удалить» убирает выбранную карточку.
- Данные учебные, хранятся в массиве в памяти. Перезагрузка страницы возвращает исходные три записи.

## Структура
- `index.html` — постоянная шапка, корневой блок, подключение Bootstrap.
- `main.js` — запуск списка и обработчик «Домой».
- `airlines.js` — массив авиакомпаний и их рейсов.
- `pages/airlines/index.js` — список, фильтр, добавление, удаление.
- `pages/airline/index.js` — подробная страница авиакомпании.
- `components/airline-card/index.js` — карточка в списке.
- `components/airline-details/index.js` — описание и таблица рейсов.
- `components/airline-back-button/index.js` — кнопка «Назад».
- `style.css` — голубая шапка, фон и размеры карточек.
- `package.json`, `package-lock.json` — зависимость Bootstrap 5.3.3.

## Bootstrap в этой работе
Используются карточки `card`, кнопки `btn`, поле `form-control`, сетка `container`, `row`, `col-md-*`, таблица `table` и `table-responsive`, вспомогательные классы отступов, цвета и flex. Стили и bundle подключены из `node_modules/bootstrap/dist/`. Отдельный дополнительный компонент по варианту преподавателем не задан.

## Что показать в Network
1. Откройте сайт в Chrome. Нажмите ⌘⌥I (Mac) или F12 (Windows).
2. Выберите вкладку Network, затем обновите страницу (⌘R / Ctrl+R).
3. Выберите запрос документа `index.html` (при открытии корня он может называться `127.0.0.1`).
4. В Headers покажите Request Method: GET и Status Code: 200. В Response покажите полученный HTML.
5. Поясните: браузер получает HTML от локального сервера, а mock-данные берёт из `airlines.js`.
